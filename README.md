# American Hit Machine

יישומון אינטראקטיבי לחקר מצעדי המוזיקה האמריקאיים ההיסטוריים.

## מטרת הפרויקט

הפרויקט מתוכנן לאפשר חיפוש לפי:

- שנה
- ז׳אנר
- סוג מצעד
- שם זמר, זמרת או להקה

סוגי המצעדים המתוכננים כוללים את מצעד Billboard השנתי, מכירות תקליטים, השמעות ברדיו, מכונות ג׳וקבוקס ומצעד Top 100 המשולב.

## גרסת הבסיס

הגרסה הנוכחית כוללת:

- ממשק מלא בעברית המותאם גם לטלפון
- סינון לפי שנה, ז׳אנר וסוג מצעד
- חיפוש לפי שם מבצע, כולל חיפוש חלקי
- הצגת עד עשר תוצאות
- העתקת שם השיר
- העתקת שם המבצע
- העתקת השיר והמבצע יחד
- העתקת הרשימה המלאה

> **חשוב:** הרשומות הנוכחיות הן נתוני הדגמה בלבד, לצורך בדיקת הממשק. הן אינן מוצגות כדירוגי Billboard רשמיים. הנתונים יוחלפו בהדרגה במידע היסטורי מאומת עם ציון מקורות.

## פרסום באמצעות GitHub Pages

במאגר יש להיכנס אל **Settings → Pages**, לבחור בפרסום מתוך הענף `main` ומהתיקייה הראשית `/root`, ולאחר מכן לשמור.
